# Telegram-бот «ГдеБЕНЗ» (gdebenz.ru)

Полнофункциональный Telegram-бот для сервиса **ГдеБЕНЗ** (https://gdebenz.ru/) — всероссийской народной карты наличия топлива и цен на АЗС в реальном времени.

Бот объединяет данные более 23 000 заправок по всей России, отметки водителей, свежие цены на стелах и городские чаты взаимопомощи.

---

## 🚀 Основные возможности

1. **Поиск АЗС рядом (GPS)**:
   - Отправка геопозиции Telegram в 1 клик для моментального нахождения ближайших заправок с точным расчетом расстояния в километрах.

2. **Поиск по городам и населенным пунктам**:
   - Полнотекстовый поиск с автоподсказками по всем городам, посёлкам и сёлам РФ (Москва, Санкт-Петербург, Краснодар, Ростов-на-Дону, Казань, Воронеж и др.).

3. **Фильтрация по маркам топлива**:
   - **АИ-92**
   - **АИ-95**
   - **АИ-98**
   - **АИ-100**
   - **Дизель (ДТ)**

4. **Сортировка «Ближе» и «Дешевле»**:
   - Моментальный поиск станций с минимальной стоимостью литра бензина или дизеля.

5. **Статусы наличия топлива в реальном времени**:
   - 🟢 **Есть** — топливо подтверждено водителями.
   - 🟡 **Очередь** — бензин есть, но на АЗС очередь.
   - 🟠 **Мало** — топливо заканчивается.
   - 🔴 **Нет** — бензин закончился.
   - 🟣 **Лимит** — отпуск ограничен (по литрам или талонам).

6. **Подробная карточка АЗС**:
   - Название сети / бренд (Лукойл, Роснефть, Газпромнефть, Татнефть, Тебойл и др.);
   - Точный адрес;
   - Таблица цен на стеле с количеством подтверждений и временем обновления;
   - Прямые ссылки для построения маршрута в **Яндекс.Навигаторе**, **Яндекс.Картах** и **2ГИС**.

7. **Отзывы и городской чат водителей**:
   - Просмотр живых отзывов и сообщений водителей по конкретной АЗС;
   - Чтение актуальных сообщений городского чата взаимопомощи водителей.

8. **Краудсорсинг (Отметка ситуации)**:
   - Возможность для водителей отмечать текущий статус на АЗС прямо из бота.

9. **Избранные АЗС**:
   - Сохранение своих постоянных заправок в «Мои АЗС» с быстрым мониторингом цен и статуса.

10. **Федеральные трассы**:
    - Быстрый выбор популярных магистралей (М-4 «Дон», М-11 «Нева», М-12 «Восток», М-5 «Урал», М-7 «Волга» и др.).

11. **Встроенная интерактивная карта (Telegram WebApp)**:
    - Кнопка «Карта (WebApp)» открывает интерактивную векторную карту сервиса прямо внутри Telegram без перехода в браузер.

## 🛠 Установка и запуск

### 1. Требования
- Установленный **Node.js** (версии 18 или новее).

### 2. Получение токена бота
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям:
   - Введите имя бота (например, `ГдеБЕНЗ — Мониторинг АЗС`);
   - Введите юзернейм бота (должен оканчиваться на `bot`, например, `gdebenz_helper_bot`).
3. Скопируйте полученный токен (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### 3. Настройка конфигурации
Откройте файл `.env` в папке проекта и вставьте ваш токен:
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
WEBAPP_URL=https://gdebenz.ru/
DEFAULT_SEARCH_RADIUS_KM=15
```

### 4. Установка зависимостей (если еще не установлены)
```bash
npm install
```

### 5. Запуск бота
```bash
npm start
```
После запуска бот выведет:
```text
✅ Бот ГдеБЕНЗ успешно запущен и ожидает сообщения!
```
